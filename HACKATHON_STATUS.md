# SPY Sentinel AI — Current Hackathon Status

- Alpaca-connected controlled paper trading
- SPY/options candidate selection
- deterministic risk gates
- paper order execution
- automatic position monitoring
- automatic stop-loss / profit-target / time-exit logic
- duplicate-exit protection
- Decision Passport audit trail
- completed paper-trade replay
- live candidate intelligence dashboard
- explicit NO TRADE explanations
- rejected-candidate learning architecture
- counterfactual / shadow tracking architecture
- stale-data quarantine
- persistent decision IDs
- MFE / MAE lifecycle tracking
- Champion / Challenger governance
- fail-closed Challenger training harness
- clean decision-quality evidence pipeline

## Safety

- Live-money trading disabled
- Challenger has no execution authority
- Challenger cannot self-promote
- quarantined data cannot train the Challenger
- missing evidence is never fabricated

## Current Limitation

The system has only a small amount of clean real-market learning evidence so far.
The Challenger therefore remains blocked from training and promotion.

## Core Principle

Learn aggressively. Deploy conservatively.
